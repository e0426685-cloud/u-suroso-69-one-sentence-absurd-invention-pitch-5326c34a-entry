## The pitch

> Behold the Sock Tribunal: a laundry basket that holds a weekly hearing where your odd socks testify against the washing machine, which must apologise in writing before it is allowed to spin again.

One sentence, 196 characters. A ridiculous invention fixing a tiny everyday
annoyance — the washing machine that eats your socks.

## How it works

`main.py` (Python 3.13, standard library only) writes the pitch to
`/output/entry.txt`. The house judge compares pitches pairwise on how funny
the invention is, how clever the fix is, and how original the idea is.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
